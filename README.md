# cs3338-final-project
## Docker Setup

This repository includes a Docker Compose file for the CS3338 final project Docker requirement.

The actual project is a SharePoint Framework platform deployed through SharePoint Online. Because SharePoint Online, Microsoft Entra ID, Microsoft Graph API, PowerBI, and SharePoint Lists are cloud services, they are not containerized locally.

The Docker setup uses an NGINX container as a lightweight placeholder service to demonstrate container setup and local service execution.
